# תוכנית — Milestone 4: בדיקות קבלה ב-Production והגנת עלויות

**מקורות:** `MILESTONES.md` (Milestone 4 + Execution Rules), `PRD.md`, `ARCHITECTURE.md` (1 — סיכונים 2–4, 2.4, 2.7, 2.8, 3.1–3.4, ADR-1, ADR-2, ADR-5, ADR-7), `DESIGN.md` (1.3, 1.4, 1.5).
**נקודת פתיחה (הקוד הקיים):** Milestones 1–3 אושרו ונדחפו, ולכן Production כבר מריץ את כל היכולות: מסך יחיד, יצירת בדיחה ב-`gpt-5`, PWA ו-Offline. תשובות `/api/joke` כבר מסומנות `Cache-Control: no-store` (`server/jokeApi.ts`). **חסר:** `vercel.json` מכיל רק את `maxDuration` — אין בו כותרות אבטחה (`nosniff`, `Referrer-Policy`, CSP). פקודות ההרצה והבדיקות ב-`CLAUDE.md` כבר מולאו. מגבלות iPhone טרם תועדו (ADR-7 משאיר לכך מקום).

**עיקרון:** זה Milestone של **בדיקה והקשחה**, לא של פיצ'רים. שינוי הקוד היחיד הוא הוספת כותרות אבטחה. אין Rate Limiting, אין ניטור/Analytics חדשים ואין שינוי מודל.

## 2. כותרות אבטחה — `vercel.json`

הוספת `headers` לכל הנתיבים (`"source": "/(.*)"`), בנוסף ל-`functions` הקיים:

| כותרת | ערך |
|---|---|
| `X-Content-Type-Options` | `nosniff` |
| `Referrer-Policy` | `strict-origin-when-cross-origin` |
| `Content-Security-Policy` | `default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; font-src 'self'; connect-src 'self'; manifest-src 'self'; worker-src 'self'; object-src 'none'; base-uri 'self'; form-action 'self'; frame-ancestors 'none'` |

נימוקים ונקודות לבדיקה בזמן הבנייה:
- **הכל מאותו Origin:** הגופנים ב-`@fontsource` (ADR-4), ה-API באותו Domain, `registerSW.js` הוא קובץ חיצוני (לא Script מוטמע) — לכן `'self'` מספיק ואין צורך ב-`'unsafe-inline'`.
- **`img-src data:`** — תמונת החתלתול הזמנית מוטמעת ב-JS כ-`data:` (ADR-7). אם בעתיד תוחלף בקובץ PNG רגיל, `data:` כבר לא נדרש, אבל אינו מזיק.
- **`worker-src 'self'`** מאפשר את ה-Service Worker (`/sw.js`) — דרישת ARCHITECTURE 2.8 שלא לחסום אותו.
- לבדוק ב-Build שאף קובץ גופן או CSS לא הוטמע כ-`data:` (Vite מטמיע קבצים קטנים מ-4KB). אם כן — להוסיף `data:` ל-`font-src` בלבד, ולא להחליש כללים אחרים.
- לבדוק שאין `style="..."` מוטמע ב-HTML שנבנה (React מגדיר סגנונות דרך DOM, ולכן אינו נחסם).
- **Cache:** אין צורך בכותרות Cache נוספות. Vercel מגיש קבצים סטטיים (כולל `sw.js` ו-`index.html`) עם `max-age=0, must-revalidate` כברירת מחדל, כך שעדכוני Service Worker מגיעים; `/api/joke` כבר `no-store`. לוודא זאת בבדיקה.
- **אין** לגעת בבדיקת `Origin` ב-API (ARCHITECTURE 2.4 מגדיר אותה כאופציונלית ולא כהגנה) — לא נדרש ב-Milestone.

## 3. בדיקות של Claude (אוטומטיות וקריאה-בלבד)

**מקומית:**
- `npm test`, `npm run build` (כולל TypeScript) — עוברים.
- `npx vercel dev --listen 3000` + `curl -I` על `/`, `/sw.js`, `/manifest.webmanifest` ו-`POST /api/joke` (גוף לא תקין, בלי פנייה ל-OpenAI): שלוש הכותרות מופיעות; `/api/joke` מחזיר `no-store`.
- טעינת `http://localhost:3000` בדפדפן המובנה: אין שגיאות CSP בקונסול, הגופנים והחתלתול מוצגים.
- חיפוש דליפת מפתח: `dist/` (קובצי ה-Bundle) ו-`git log -p` — אין `OPENAI_API_KEY` עם ערך ואין מחרוזות בתבנית `sk-`. `.env` לא נקרא ולא נכלל ב-Repository (`git ls-files`).

**Preview (באישור):** פתיחה בדפדפן המובנה (בעל המוצר מתחבר ל-Vercel אם נדרש) — הכותרות קיימות, ה-Service Worker נרשם (`navigator.serviceWorker.controller` אחרי רענון), אין שגיאות CSP, יצירת בדיחה אחת עובדת.

**Production (לפני ואחרי הדחיפה, קריאה-בלבד, ללא עלות AI):**
- `https://<כתובת-production>` מחזיר `200` ב-HTTPS; `http://` מפנה ל-HTTPS.
- `GET /api/joke` → `405`; `POST` עם JSON לא תקין → `400`; נושא של 101 תווים → `400`; כולם עם `Cache-Control: no-store` וללא המפתח בגוף התשובה.
- `/manifest.webmanifest` ו-`/sw.js` נגישים.
- אחרי הדחיפה בלבד: שלוש כותרות האבטחה קיימות ב-`/` וב-`/api/joke`.

יצירת בדיחות אמיתיות ב-Production (שעולות כסף) נעשית רק בבדיקות הטלפון של בעל המוצר ובבדיקת Preview בודדת.

## 4. הגנת עלויות — בדיקה מודרכת עם בעל המוצר

Claude מדריך בשפה פשוטה; בעל המוצר מבצע ומדווח מה הוא רואה:
1. **OpenAI:** בפרויקט שבו נמצאים שני המפתחות — מוגדרת **תקרת הוצאה חודשית קשיחה** (סכום שבעל המוצר בוחר) והתראות תקציב לדוא"ל. לפני ההדרכה Claude בודק בתיעוד הרשמי העדכני של OpenAI איפה ההגדרות נמצאות כרגע.
2. **הסבר לבעל המוצר:** כשהתקרה מושגת, כל לחיצה על "צור בדיחה" מציגה את הודעת השגיאה הכללית עד תחילת החודש הבא (או עד העלאת התקרה). זה צפוי ולא באג.
3. **Vercel:** אילו מפתחות מוגדרים באיזו סביבה (Production = מפתח Production; Preview = מפתח פיתוח), בלי להציג ערכים. תוכנית Hobby מיועדת לשימוש אישי לא מסחרי — בעל המוצר מאשר שזה המצב (אחרת נדרשת תוכנית Pro; זו החלטה שלו).
4. **אין** Rate Limiting ואין מכסות למשתמשים (PRD, ARCHITECTURE סיכון 2).
